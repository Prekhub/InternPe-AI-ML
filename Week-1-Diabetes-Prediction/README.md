# InternPe AI/ML Internship Projects

Welcome to my **InternPe AI/ML Internship** repository. This repository contains all the projects I completed during my 6-week internship, where I learned Machine Learning concepts and implemented real-world predictive models using Python and Scikit-learn.

## Projects

### 📌 Week 1 – Diabetes Prediction Model

* Built a Machine Learning model to predict whether a person is diabetic based on medical parameters.
* Performed data preprocessing, feature scaling, model training, and prediction.
* **Algorithm:** Support Vector Machine (SVM)

### 📌 Week 2 – Car Price Prediction Model

* Developed a regression model to estimate used car prices based on features such as company, year, fuel type, and kilometers driven.
* Applied data cleaning, preprocessing, one-hot encoding, and Linear Regression.
